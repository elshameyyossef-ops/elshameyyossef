## 🚀 Featured Projects

### 🏥 Hospital AI Diagnostic System (Graduation Project)
A Streamlit app with two models plus a companion Power BI dashboard.
- **Insurance cost prediction:** regression on a ~57-column dataset, leakage columns removed, several models compared (Linear / Ridge / Lasso / Polynomial / RF / XGBoost).
